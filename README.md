# Dynamic Color Profiles (DCP)

Dynamic Color Profiles is a simple, lightweight, portable and straight-forward to use filter program for NVIDIA & AMD GPUs that allows you to quickly create, save and load custom desktop color settings.

Simply adjust the sliders to your desire, name your profile and click save. Use the dropdown menu to load a profile. You can also load a saved profile through the system tray by clicking the icon with a right click.

DCP utilizes dlls that came with your drivers to calculate and modify your desktop color settings, therefore the values displayed on the sliders should be 1:1 to Nvidia's control panel and AMD's adrenaline video settings.

# Will I get banned in X game for using DCP?

DCP doesn't inject or interact with any running window or process in your PC, DCP loads and uses your nvidia's dlls that have been installed when you first downloaded your drivers. Unless the game you're playing has a really bad or funky Anti cheat, you should be good...
