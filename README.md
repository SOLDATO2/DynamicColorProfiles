# Dynamic Color Profiles (DCP)

Dynamic Color Profiles is a simple, lightweight, portable and straight-foward to use filter program that allows you to quickly create, save and load custom desktop color settings.

Currently only NVIDIA cards are supported, this is because DCP uses NVIDIA dlls to customize the desktop colors. 

Simply adjust the sliders to your desire, name your profile and click save. Use the dropdown menu to load a profile. You can also load a saved profile through the system tray by clicking the icon with a right click.

Since DCP uses nvidias dlls to adjust the color settings, the sliders values should be 1:1 to Nvidia's control panel sliders.

# Will I get banned in X game for using DCP?

DCP doesn't inject or interact with any running window or process in your PC, DCP loads and uses your nvidia's dlls that have been installed when you first downloaded your drivers, basically DCP acts as a mini nvidia control panel. In other words, unless the game you're playing has a really bad or funky Anti cheat, you should be good...
